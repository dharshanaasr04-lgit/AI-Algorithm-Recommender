# AI Algorithm Recommender

## Project Overview

AI Algorithm Recommender is a simple Machine Learning application that recommends a suitable Machine Learning algorithm based on the user's project requirements.

The user provides details such as problem type, dataset size, number of features, accuracy, speed, and interpretability. The trained Machine Learning model then recommends a suitable algorithm.

## Features

- Recommends suitable Machine Learning algorithms
- Supports Classification, Regression and Clustering
- Shows recommendation confidence
- Provides a simple Streamlit interface
- Easy to use for beginners

## Technologies Used

- Python
- Machine Learning
- Scikit-learn
- Pandas
- NumPy
- Streamlit

## How to Run

1. Open the project in Visual Studio Code.
2. Install the required libraries using:
   `pip install -r requirements.txt`
3. Run the application using:
   `streamlit run app.py`
4. Open the URL provided by Streamlit in your web browser.
5. Enter the required details and click **Recommend Algorithm**.
