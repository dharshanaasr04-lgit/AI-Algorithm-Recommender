# 🤖 AI Algorithm Recommender

## 📌 Overview

AI Algorithm Recommender is a machine-learning-based system that recommends suitable machine learning algorithms based on the characteristics and requirements of a given problem.

The system analyzes different problem and dataset characteristics and uses a machine learning model to recommend suitable algorithms.

---

## 🎯 Objective

The main objective of this project is to help users select an appropriate machine learning algorithm without requiring extensive knowledge of different machine learning algorithms.

The system takes user requirements as input, processes the information, and predicts suitable algorithms.

---

## 🛠️ Technologies Used

- C++
- Python
- MySQL
- RDBMS
- Scikit-learn
- Git
- GitHub
- Visual Studio Code

---

## 🤖 Artificial Intelligence

The project uses Machine Learning to learn patterns from a dataset containing different problem characteristics and suitable machine learning algorithms.

The trained model will predict suitable algorithms for new user requirements.
